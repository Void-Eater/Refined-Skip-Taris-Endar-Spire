# Refined-Skip-Taris-Endar-Spire
This mod adds three dialog options to Trask's initial dialog to allow you to skip either the Endar Spire or Taris as both light or dark side options.


This mod adds three dialog options to Trask's initial dialog to allow you to skip either the Endar Spire or Taris as both light or dark side options.

The mod was originally made by Lit Ridl on lucasforums, and then updated and reuploaded by USMCFRSD again. USMCFRSD added some great features, including the mod actually marking all the necessary quests as complete in order to prevent the game freaking out in future main quests. They hadn't maintained the mod in ten years, and I got permission from them to take over maintenance of this mod, so future versions will be uploaded here. I took the time to comb through the comments of Super Skip Taris and Endar Spire to figure out people's issues, complaints and any major front-facing bugs with the mod.

# Change Log
- Brejik's gear is now given to the player correctly. None of it is missed on Skipping Taris. This fix comes courtesy of a comment from a now deleted user on Super Skip Taris and Endar Spire
- Bastila's Lightsaber will now correctly appear in your inventory when skipping Taris, courtesy of the same comment as the previous fix.
- I believe I have rectified the invincibility glitch people were experiencing when skipping both the Endar Spire and Taris. This will require more testing, and I will be watching comments closely to verify this.

# Installation instructions

**INSTALLATION (TSL PATCHER):**
- Extract the tslpatchdata and TSLPatcher into the same directory
- Run TSLPatcher and select install location if prompted

**INSTALLATION (MANUAL):**

**WARNING - ONLY DO THIS IF NO OTHER MODS AFFECT dialog.tlk IN YOUR OVERRIDE!**
- Extract tslpatchdata from the zip file
- Copy & Paste all of the files within tslpatchdata into your Override folder
- Double check any conflicting files and confirm file replacement one-by-one
**DO NOT INSTALL THIS USING VORTEX. IT SEEMS TO HAVE ISSUES WITH IT.
MAKE SURE YOU INSTALL THIS MOD AS THE VERY LAST MOD. OTHER MODS COULD OVERWRITE WHAT THIS MOD CHANGES AND STOP IT WORKING.**

**UNINSTALLATION:**

Either replace the dialog.tlk file in you SWKOTOR directory with a version prior to the first attempted installation of this mod, or uninstall SWKOTOR, reboot, clean the directory, and reinstall.

**NOTES:**

Installing this mod more than once per dialog.tlk and/or SWKOTOR installation will result in the reappearance of all the options in Trask's dialog. The original information released with the mod is included in the tslpacthdata directory and the TSLPatcher.
